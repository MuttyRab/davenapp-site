# Daven introduction video

`assets/daven-introduction.mp4` is a silent, 19-second, 1080 × 1920 introduction for voluntary sharing. All messages are on screen. It has no music, testimonials, generated app screens, or customer claims.

Rebuild from the repository root with Node and FFmpeg installed:

```sh
node marketing/render-demo.mjs
```

The render uses only the existing Daven icon and a crop of the existing real `assets/shot-reader.png` screenshot. The crop retains the Ashrei Hebrew passage unchanged; the dated service header, retired duration estimate and controls are outside the frame. This is an editorial introduction, not a recording of a new app release or proof of native QA. The remaining scenes are marketing typography, not simulated app UI.

Frank Ruhl Libre Regular and Assistant SemiBold are unmodified fonts used by Daven, distributed here with their SIL Open Font License notices. The renderer runs locally and makes no network requests. Render intermediates are temporary and are not deployed.

Claims are limited to the existing free daily siddur, all 150 Tehillim, four nusachim, offline reading and no account needed to start. The closing frame discloses optional in-app purchases. Source: the app's feature boundaries and the public website as reviewed on September 16, 2026.

This file is available on the existing share page for people who choose to recommend Daven. Publishing it does not establish reach, downloads, new customers, or paid conversions. No automatic social posting is configured.
